About GEO

GEO is a versatile app that helps users create and visualize plots from proposal charts to well summary logs, development charts, drilling time charts, core analysis plots, and gas ratio logs. GEO can guide and assist drilling operations. Each template provides information for plotting curves and calculations after data loading, supporting well planning and comparison between simulated and actual data points.

For example, processing ODF files in real time for data analysis and interpretation enables correlation analysis, drilling log updates, and data visualizations that guide key decision-making.

For more information, visit the official GEO application page .
