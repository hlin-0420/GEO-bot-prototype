About GEO

GEO is a versatile app that helps users to create and visualise plots from proposal charts to well summary logs, development charts, drilling time charts, core analysis plots, and gas ratio logs. GEO can guide and assist with the drilling operation. Each template provide information for plotting curves and calculating after loading data files where the data can be applied for planning wells as reference between the simulated and actual data points.


For example, Open ODF file processed in real-time for data analysis and interpretation applies correlation analysis, drilling log updates, and data visulisations to guide key decision-makings.

For more information, visit the official GEO application page .
